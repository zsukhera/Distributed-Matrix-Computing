HOW TO RUN — All Questions (Dense, Sparse, Parallel Training)
==============================================================

STEP 1 — Build
--------------
    make              # build all three (task1, task2, task3)
    make task1        # build Question 1 only
    make task2        # build Question 2 only
    make task3        # build Question 3 only

STEP 2 — Run
------------
General form:
    OMP_NUM_THREADS=<threads> mpirun -n <processes> --hostfile hosts ./task1 <N>

  <N>         matrix size (8 for quick check, 1000 / 2000 / 4000 for benchmarks)
  <processes> number of MPI processes  (1, 2, 4, 8 ...)
  <threads>   number of OpenMP threads per process (1, 2, 4 ...)

  The hosts file (./hosts) lists the cluster nodes and available slots:
      master slots=8
      slave1 slots=8
      slave2 slots=8
  Adjust slots to match the actual CPU count on each node (run: nproc).


TASK 1.1 — OpenMP only (single process, vary threads)
------------------------------------------------------
    OMP_NUM_THREADS=1 mpirun -n 1 --hostfile hosts ./task1 1000
    OMP_NUM_THREADS=2 mpirun -n 1 --hostfile hosts ./task1 1000
    OMP_NUM_THREADS=4 mpirun -n 1 --hostfile hosts ./task1 1000

    OMP_NUM_THREADS=1 mpirun -n 1 --hostfile hosts ./task1 2000
    OMP_NUM_THREADS=4 mpirun -n 1 --hostfile hosts ./task1 2000


TASK 1.2 — Version A (MPI Scatter / Bcast / Gather)
----------------------------------------------------
    mpirun -n 1 --hostfile hosts ./task1 2000
    mpirun -n 2 --hostfile hosts ./task1 2000
    mpirun -n 4 --hostfile hosts ./task1 2000
    mpirun -n 8 --hostfile hosts ./task1 2000

    mpirun -n 4 --hostfile hosts ./task1 4000
    mpirun -n 8 --hostfile hosts ./task1 4000


TASK 1.3 — Version B (blocking ring)
-------------------------------------
Same commands as Task 1.2 — just swap the version inside the binary
or compile separately if versions are split into separate files.


TASK 1.4 — Version C (non-blocking ring + OpenMP)
--------------------------------------------------
One process per core:
    OMP_NUM_THREADS=1 mpirun -n 8 --hostfile hosts ./task1 4000

Hybrid (one process per node, threads inside):
    OMP_NUM_THREADS=4 mpirun -n 2 --hostfile hosts ./task1 4000


CORRECTNESS CHECKS (via make targets)
--------------------------------------
    make test8       # N=8,  p=1/2/3  — full matrix, compare Table 1(a)
    make test1000    # N=1000, threads 1/2/4 — five entries, compare Table 1(b)
    make test2000    # N=2000, threads 1/2/4
    make test4000    # N=4000, threads 1/4
    make test        # run all of the above in sequence

NOTES
-----
- If mpirun hangs, try adding --oversubscribe flag:
      mpirun --oversubscribe -n 4 ./task1 1000
