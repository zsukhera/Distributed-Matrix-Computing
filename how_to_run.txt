HOW TO RUN — All Questions (Dense, Sparse, Parallel Training)
==============================================================

STEP 1 — Build
--------------
    make              # build all three (task1, task2, task3)
    make task1        # build Question 1 only
    make task2        # build Question 2 only
    make task3        # build Question 3 only

STEP 2 — Run
------------
General form:
    OMP_NUM_THREADS=<threads> mpirun -n <processes> --hostfile hosts ./task1 <N>

  <N>         matrix size (8 for quick check, 1000 / 2000 / 4000 for benchmarks)
  <processes> number of MPI processes  (1, 2, 4, 8 ...)
  <threads>   number of OpenMP threads per process (1, 2, 4 ...)

  The hosts file (./hosts) lists the cluster nodes and available slots:
      master slots=1
      slave1 slots=1
      slave2 slots=1
  Each VM has 1 core. p > 3 requires --oversubscribe.


TASK 1.1 — OpenMP only (single process, vary threads)
------------------------------------------------------
    OMP_NUM_THREADS=1 mpirun -n 1 --hostfile hosts ./task1 1000
    OMP_NUM_THREADS=2 mpirun -n 1 --hostfile hosts ./task1 1000
    OMP_NUM_THREADS=4 mpirun -n 1 --hostfile hosts ./task1 1000

    OMP_NUM_THREADS=1 mpirun -n 1 --hostfile hosts ./task1 2000
    OMP_NUM_THREADS=4 mpirun -n 1 --hostfile hosts ./task1 2000


TASK 1.2 — Version A (MPI Scatter / Bcast / Gather)
----------------------------------------------------
Program arguments:  ./task1 <N> 1.2      (second arg selects the task: 1.1 | 1.2 | all)

Each VM has 1 core (hosts: slots=1 each), so p > 3 needs --oversubscribe.
--map-by node spreads ranks round-robin: master, slave1, slave2, master, ...

    make deploy                                   # copy the new binary to slave1/slave2 FIRST

    mpirun -n 1 --hostfile hosts ./task1 2000 1.2
    mpirun -n 2 --hostfile hosts ./task1 2000 1.2
    mpirun -n 3 --hostfile hosts ./task1 2000 1.2
    mpirun --oversubscribe --map-by node -n 4 --hostfile hosts ./task1 2000 1.2
    mpirun --oversubscribe --map-by node -n 8 --hostfile hosts ./task1 2000 1.2

    mpirun --oversubscribe --map-by node -n 4 --hostfile hosts ./task1 4000 1.2
    mpirun --oversubscribe --map-by node -n 8 --hostfile hosts ./task1 4000 1.2

The output lists which host each rank runs on, plus timings for
Scatterv / Bcast / Multiply / Gatherv and the five check entries.


TASK 1.3 — Version B (blocking ring)
-------------------------------------
Same commands as Task 1.2 — just swap the version inside the binary
or compile separately if versions are split into separate files.


TASK 1.4 — Version C (non-blocking ring + OpenMP)
--------------------------------------------------
One process per core:
    OMP_NUM_THREADS=1 mpirun -n 8 --hostfile hosts ./task1 4000

Hybrid (one process per node, threads inside):
    OMP_NUM_THREADS=4 mpirun -n 2 --hostfile hosts ./task1 4000


QUESTION 2 — Sparse matrix (social network)
============================================
Program arguments:  ./task2 [n] [task]
    n     number of users (default: 100000 and 1000000)
    task  2.1 | 2.2 | 2.3 | 2.4 | all   (default: all)
Every version prints H(0,0), H(12345,7), H(n-1,15) with 12 decimals and
"OK"/"MISMATCH" against Table 3, plus a per-process table (rows, links,
compute, comm, wait, bytes received per step).

Run everything and save the log (on master):
    ./run_q2.sh                       # -> results/q2_outputs.txt

Or individually (make deploy first!):

TASK 2.1 — serial, OpenMP static vs dynamic,64 (one process)
    OMP_NUM_THREADS=1 mpirun -n 1 --hostfile hosts ./task2 100000 2.1
    OMP_NUM_THREADS=4 mpirun -n 1 --hostfile hosts ./task2 1000000 2.1

TASK 2.2 — Version A, MPI_Allgatherv of the whole H every step
    mpirun -n 2 --hostfile hosts ./task2 1000000 2.2
    mpirun --oversubscribe --map-by node -n 8 --hostfile hosts ./task2 1000000 2.2

TASK 2.3 — Version B, halo exchange (runs with AND without overlap)
    mpirun -n 2 --hostfile hosts ./task2 1000000 2.3
    mpirun --oversubscribe --map-by node -n 8 --hostfile hosts ./task2 1000000 2.3

TASK 2.4 — equal-rows vs equal-links blocks (Version B)
    mpirun --oversubscribe --map-by node -n 4 --hostfile hosts ./task2 1000000 2.4
    mpirun --oversubscribe --map-by node -n 8 --hostfile hosts ./task2 1000000 2.4
  Hybrid, one process per node:
    OMP_NUM_THREADS=<cores per node> mpirun -n 3 --hostfile hosts ./task2 1000000 2.4

Expected (Table 3, after T = 10 steps):
  n          links       H(0,0)          H(12345,7)      H(n-1,15)
  100,000    1,020,227   0.493896795310  0.497876802886  0.497973641990
  1,000,000  10,160,271  0.500882792529  0.499154198420  0.492279183027

NOTES
-----
- Cluster network: each VM has a NAT adapter (enp0s3) with the SAME IP
  10.0.2.15 on every machine, which makes MPI hang ("No route to host").
  ~/.openmpi/mca-params.conf and ~/.prte/mca-params.conf on ALL nodes
  restrict MPI to the host-only network:
      btl_tcp_if_include = 192.168.56.0/24
      oob_tcp_if_include = 192.168.56.0/24
  (one-off equivalent: mpirun --mca btl_tcp_if_include 192.168.56.0/24
   --mca oob_tcp_if_include 192.168.56.0/24 ...)

- Every node must run the SAME binary. After every `make`, run `make deploy`.
  Mismatched binaries on master/slaves make the job hang.

- If mpirun hangs, try adding --oversubscribe flag:
      mpirun --oversubscribe -n 4 ./task1 1000

- To clean the build:
      make clean

- Local testing on the WSL laptop (NOT the cluster): MPI_Init hangs there
  because one of hwloc's GPU plugins hangs on WSL. Skip those plugins:
      export HWLOC_COMPONENTS=-pci,-linuxio,-opencl,-cuda,-nvml,-rsmi,-levelzero,-gl
      mpirun --oversubscribe -n 4 ./task2 100000
